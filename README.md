

\# Placement Readiness Intelligence System (PRIS)



\## Project Overview

PRIS is an AI-powered application that evaluates a candidate's readiness for a target job using resume analysis, job description matching, machine learning, and retrieval-augmented generation (RAG).



\## Key Features

\- Resume PDF text extraction

\- Job description analysis using Gemini

\- Matched and missing skill identification

\- Skill gap analysis

\- Machine learning-based placement prediction signal

\- RAG-based learning recommendations

\- Personalized improvement roadmap

\- Interview preparation suggestions

\- Streamlit dashboard

\- Downloadable PDF report



\## Machine Learning

The project compares Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting.



Evaluation metrics include Accuracy, Precision, Recall, and F1 Score. Gradient Boosting was selected as the final candidate model based on model comparison.



\## Technologies

\- Python

\- Pandas and NumPy

\- Scikit-learn

\- Gemini API

\- TF-IDF and Cosine Similarity

\- Streamlit

\- PyPDF

\- Joblib

\- ReportLab



\## Run Locally

1\. Clone this repository.

2\. Create and activate a Python virtual environment.

3\. Install dependencies using `pip install -r requirements.txt`.

4\. Configure your Gemini API key securely using an environment variable.

5\. Run `streamlit run app.py`.



\## Important

Never commit API keys, passwords, or other secrets. Configure the required API key before using AI features.
